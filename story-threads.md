# Ongoing story threads

Read this file at the start of each briefing, right after checking digest.txt's
build date. When today's digest contains a genuine follow-up to one of these
threads, reference the earlier context naturally in the brief ("as previously
flagged...", "following up on the FIFA story...", "as a reminder, Wednesday's
eclipse...") instead of reporting it as if it were appearing for the first
time. This is what gives the daily brief continuity despite having no memory
between runs otherwise.

At the end of each day, update this file:
  - Add new threads worth tracking going forward (a dated event coming up, an
    ongoing crisis or investigation, a deal or negotiation without a resolved
    outcome yet).
  - Update existing entries with the latest status when today's digest moved
    them forward.
  - Remove anything resolved, or that has gone quiet for 10+ days with no
    update in any digest.
  - Keep this to roughly 15-20 active threads. If it grows past that, prune
    the least newsworthy ones first rather than letting it grow unbounded.

Commit this file alongside briefing.txt each day (same commit is fine) so the
next day's fresh session inherits it.

Format: one entry per thread, dated to when first flagged or last updated,
one or two sentences of context - enough for a same-day reader to know what
it's referring to, not a full recap.
