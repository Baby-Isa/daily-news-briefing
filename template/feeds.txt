# The sources this briefing reads every morning.
#
# One feed per line:   lane | outlet | url | flags
#
# TO ADD A SOURCE: add a line. Use an existing lane name, or invent a new
# one - new lanes appear in the digest automatically. Lanes are only a
# filing system for the digest; what the briefing SAYS is decided by
# profile.md, not by this file.
# TO REMOVE A SOURCE: delete its line, or put a # in front of it.
# TO FOLLOW A NAMED COMPANY, PERSON OR TOPIC with no feed of its own, use a
# Google News search line under the lane "Watchlist" - see the pattern at
# the bottom of feeds-library.txt.
# Before adding any new feed, test it:  python3 tools/test_feed.py "<url>"
#
# Flags (optional, in the fourth field):
#   FULLTEXT   fetch the whole article, for sources that feed the analysis
#   QUIET      publishes rarely; silence for weeks is normal, not a fault
#   RARE       publishes irregularly; never report as stale
#   FILTER:a,b keep only items whose title or summary contains a keyword
#   EXCLUDE:a,b drop items whose TITLE contains a keyword
# FILTER and EXCLUDE swallow the rest of the line, so each must come last
# and only one may appear on a line.
