# Run log

One line per day, newest first, written by the daily run as its last
action whether the day succeeded or not. Read this before guessing why a
day looks wrong. No line for today, by the time you would expect one,
means the run has not fired or failed before it could write.

`YYYY-MM-DD - STATUS - what happened.`

STATUS is OK (drafted, checked, published, render confirmed), PARTIAL
(published but a check failed), FAILED (nothing published: say why),
or REVIEW (the weekly self-review).
